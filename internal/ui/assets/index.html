            登录安全提醒：使用 CLI 唤起 Arc 等系统浏览器时的网络条件
            
运行 peaceclaude cli 时，CLI 进程内的接口请求 100% 强制经本地代理 (127.0.0.1:18897) 走静态美国出口；但首次登录由终端自动唤起 Arc / 系统默认浏览器时，GUI 浏览器进程不会继承终端环境变量，而是读取 macOS 系统 PAC。因此必须保持「系统浏览器 PAC」开启（当前守护进程启动已默认自动开启）；若您手动关闭了 PAC，请勿直接使用系统浏览器完成登录，应点击控制台「隔离浏览器登录」或运行 peaceclaude login-browser --profile <ID>。
